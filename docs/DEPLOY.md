# النشر المجاني على Render

نشر بخدمة واحدة: Django يقدّم الـ API **والواجهة المبنية** من نفس الأصل
(بلا CORS)، مع قاعدة PostgreSQL مجانية. الملفات جاهزة: `Dockerfile` ·
`render.yaml` · `backend/start.sh`.

## الخطوات (مرّة واحدة)

1. ادخل إلى <https://render.com> وسجّل الدخول بحساب **GitHub** (مجاني).
2. من اللوحة: **New → Blueprint**.
3. اختر مستودع `Lebid15/wtn` والفرع `claude/website-clone-auth-access-xp4oj8`
   (أو `main` بعد الدمج). سيقرأ Render ملف `render.yaml` تلقائياً.
4. اضغط **Apply**. سيُنشئ Render:
   - قاعدة `wtn-db` (PostgreSQL، خطة free).
   - خدمة ويب `wtn` (Docker، خطة free) — تبني الواجهة + الخلفية.
5. أول إقلاع يشغّل الترحيلات ويزرع البيانات التجريبية تلقائياً (مرّة واحدة).
6. بعد اكتمال البناء (~3–5 دقائق) ستحصل على رابط مثل:
   `https://wtn.onrender.com` — افتحه وسجّل الدخول بأحد حسابات الاختبار.

## ملاحظات

- **الخطة المجانية تنام** بعد ~15 دقيقة خمول؛ أول طلب بعدها يستغرق ~دقيقة
  (إقلاع بارد) ثم يعمل بسرعة. قاعدة البيانات المجانية صالحة ~90 يوماً.
- المتغيّرات (`SECRET_KEY` يُولَّد تلقائياً · `DEBUG=0` · `DB_*` من القاعدة)
  مضبوطة في `render.yaml` — لا حاجة لضبط يدوي.
- للتشغيل محلياً بنفس نمط الإنتاج:
  ```bash
  cd frontend && npm run build
  cd ../backend && FRONTEND_DIST=../frontend/dist DEBUG=0 \
    venv/bin/gunicorn config.wsgi:application --bind 127.0.0.1:8000
  ```
