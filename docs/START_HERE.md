## ما هو المشروع
نظام **لوحة وكلاء لشحن الألعاب** متعدد المستأجرين (Multi-Tenant SaaS)، عربي RTL،
مبني بإذن من نظام تركي مرجعي، للسوق السوري. الهدف: المالك يصير الشركة التي تبيع
النسخ. **التصميم غير متجاوب** (عرض ثابت 1366px، مطابق للمرجع).

## الحزمة التقنية
- **Backend:** Django + DRF + PostgreSQL (مجلد `backend/`).
- **Frontend:** React + Vite + TypeScript (مجلد `frontend/`).
- تفاصيل: `docs/ARCHITECTURE.md` · `docs/DATABASE_SCHEMA.md`.

## الأدوار الأربعة (راجع `docs/ROLES.md`)
| برمجياً | مصطلح المالك | لوحته |
|---------|--------------|-------|
| `platform_owner` | مالك المنصّة | `/platform` |
| `tenant_admin` | صاحب المتجر | لوحة الإدارة (`/dealers` …) |

## التشغيل والاختبار (البيئة السحابية مؤقتة — أعد التشغيل عند الحاجة)
```bash
# قاعدة البيانات
sudo service postgresql start
# الخلفية
cd backend && DB_PASSWORD=wtn_dev_pass venv/bin/python manage.py runserver 127.0.0.1:8000 &
# الترحيلات + البيانات (إن لزم)
venv/bin/python manage.py migrate
venv/bin/python manage.py seed_demo && venv/bin/python manage.py seed_catalog \
  && venv/bin/python manage.py seed_providers && venv/bin/python manage.py seed_pools \
  && venv/bin/python manage.py seed_payments && venv/bin/python manage.py seed_platform
# الواجهة
cd ../frontend && npm run dev -- --host 127.0.0.1 --port 5173 &
```
> تحقّق بصري: استخدم Chromium المثبّت (`/opt/pw-browsers/chromium-*/chrome-linux/chrome`)
> عبر playwright-core لالتقاط لقطات — النمط مستخدم في كل الجلسة.
