## المرحلة 1 — القلب (Core) ⭐

الأولوية القصوى. بدونها لا شيء يعمل.

- [ ] **المصادقة:** تسجيل دخول (login_id + password) + 2FA (TOTP).
- [ ] **تعدد المستأجرين:** حلّ النطاق الفرعي + عزل `tenant_id`.
- [ ] **الأدوار (RBAC):** platform_owner / tenant_admin / bayi / …
- [ ] **الهيكل العام (Layout):** Navbar + 12 أيقونة تنبيه + Sub-nav + Footer —
      مطابق للمرجع، بأبعاد ثابتة، RTL عربي.
- [ ] **i18n + Theming:** عربي أساسي + لون/شعار لكل مستأجر.

**المخرج:** تدخل بحساب، تشوف اللوحة بالشكل المطابق (فارغة من البيانات).

## المرحلة 2 — المحفظة (Wallet) 💰

- [ ] الرصيد الموقّع (±) + الحد الائتماني (Kredi Limiti).
- [ ] دفتر الأستاذ (Ledger) — كل حركة تسجّل before/after ذرّياً.
- [ ] شحن/خصم يدوي من الأدمن (Finans İşlem).
- [ ] حساباتي (Hesaplarım) + إشعارات الدفع (Ödeme Takip) + موافقة/رفض.
- [ ] كشف الحساب (Hesap Hareketleri).

**المخرج:** تشحن رصيد وكيل، تشوف الحركات، الرصيد يتحدّث صح.

## المرحلة 3 — الكتالوج والتسعير (Catalog & Pricing) 🎮

- [ ] الكتالوج المركزي (Global Games) + تبنّي الألعاب.
- [ ] الألعاب (Oyunlar) — بطاقات + drag&drop + تفاصيل + إعدادات اللعبة.
- [ ] المنتجات (Ürünler) — Maliyet/Tavsiye/Küpür/Parçalı/إيقاف مؤقت.
- [ ] مجموعات الأسعار (Fiyat Grupları) + Dolar Kuru + أوضاع التسعير.
- [ ] إعدادات أسعار الوكلاء (Bayi Fiyat Ayarları) + السعر الخاص (override).
- [ ] محرّك حساب السعر النهائي (منطق §هـ في المخطط).

**المخرج:** تضيف لعبة ومنتجات، تسعّرها لمجموعات، كل وكيل يشوف سعره.

## المرحلة 4 — الطلبات والمزوّدون (Orders & Providers) 🔌

أعقد مرحلة — قلب العمليات.

- [ ] المزوّدون (Apileri) + الأنواع (znet/card/pool/manual).
- [ ] مطابقة المنتجات (Ürün Eşleştirme) + التوجيه 3-مستويات (fallback).
- [ ] تنفيذ الطلب (Takip): يدوي (Yükleyici queue) + تلقائي (API).
- [ ] آلة حالات الطلب (pending→processing→success/cancelled/stuck).
- [ ] Parçalı (تقسيم الطلب) + PIN + SMS + Kara Liste.
- [ ] بنك البينات (Havuz) — تخزين + تسليم تلقائي.
- [ ] الطوابير (BullMQ) + تحديث الأسعار المجدول + Zarar Ayarı.

**المخرج:** وكيل يرسل طلباً → يُنفّذ (تلقائي أو يدوي) → يستلم PIN، والرصيد يُخصم.

## طريقة العمل في كل مرحلة

1. أبني الموديول (backend + frontend).
2. **تجرّبه أنت** وتقارنه بالمرجع.
3. لو ناقصة تفصيلة → صورة واحدة أو شرح منك → أكمّلها.
4. ننتقل للمرحلة التالية.

> **البداية المقترحة بعد اعتماد هذه الخطة:** المرحلة 0 (تهيئة المشروع)،
> ثم مباشرة المرحلة 1 (القلب) لأنها تُظهر الشكل المطابق للمرجع بسرعة.
