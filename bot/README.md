# بوت واتساب — wtn

برنامج صغير يعمل على **جهاز يبقى مشتغلاً**، يسأل الموقع كل ثلاث ثوانٍ عن
الرسائل المطلوب إرسالها فيرسلها بتهدئة، ويحمل جلسة واتساب لكل متجر.

الموقع نفسه لا يتّصل بواتساب إطلاقاً — هو يكتب في الطابور وحسب.

---

## لماذا برنامج منفصل؟

استضافة الموقع المجانية **تنام بعد ربع ساعة خمول**، وواتساب يحتاج اتصالاً
دائماً لا ينقطع. فلو عاش داخل الموقع لانقطعت الجلسة عشرات المرّات يومياً —
وهو أسرع طريق إلى حظر الرقم.

وهذا البوت **يسأل ولا يُنادى**: لا يحتاج عنواناً عاماً ولا منفذاً مفتوحاً،
فيعمل من أي جهاز خلف أي راوتر. وحين تنتقل إلى سيرفر مدفوع لا يتغيّر إلا سطر
`SITE_URL` — والجلسة تُستأنف بلا مسح QR جديد، لأن مفاتيحها في قاعدة الموقع
لا على قرص الجهاز.

---

## التشغيل — خمس خطوات

```bash
cd bot
npm install
npm run keygen          # ← ولّد مفتاح التشفير (مرّة واحدة في عمر المشروع)
cp .env.example .env    # ثم املأ القيم الثلاث
npm start
```

القيم الثلاث في `.env`:

| القيمة | من أين |
|--------|--------|
| `SITE_URL` | عنوان موقعك — `https://wtn.onrender.com` |
| `INTERNAL_API_KEY` | سرّ تخترعه، **وتضعه أيضاً في متغيّرات بيئة الموقع** بالاسم نفسه |
| `BOT_ENCRYPTION_KEY` | ناتج `npm run keygen` — احتفظ بنسخة منه |

> ⚠ ما لم يُضبط `INTERNAL_API_KEY` **على الموقع أيضاً**، تبقى الواجهة الداخلية
> مغلقة تماماً (503) ولن يتّصل البوت. وهذا مقصود: لا نترك باباً مفتوحاً.

ثم من لوحة صاحب المتجر: **الإعدادات ← واتساب ← ربط واتساب**، وامسح الرمز من
هاتف الرقم (واتساب ← الأجهزة المرتبطة ← ربط جهاز).

---

## ماذا يحدث حين يكون البوت مطفأً؟

**لا شيء يضيع.** الضغط على أزرار الإرسال يكتب الرسائل في طابور قاعدة البيانات
بحالة «بانتظار الإرسال». تشغّل البوت فينطلق فيها من حيث توقّف.

وتُري صفحة **الإعدادات ← واتساب** تنبيهاً واضحاً حين يكون مطفأً.

## احتياطات حظر الرقم — اقرأها

واتساب لا يعتمد هذه الطريقة رسمياً (Baileys يتحدّث ببروتوكول واتساب ويب)،
والإرسال الجماعي أعلى مصادر الخطر. المطبَّق في البرنامج:

| الاحتياط | أين |
|----------|-----|
| تأخير عشوائي 4–10 ثوانٍ بين كل رسالتين | يضبطه المالك من صفحة الإعدادات |
| استراحة بعد كل دفعة (25 رسالة ← 5 دقائق) | نفس الصفحة |
| التحقّق أن الرقم مسجَّل على واتساب قبل الإرسال (`onWhatsApp`) | `session.js` |
| النصّ يحمل اسم الوكيل ورصيده — فلا رسائل متطابقة حرفياً | قالب الموقع |
| `markOnlineOnConnect: false` و`syncFullHistory: false` | `session.js` |

**ويبقى عليك:**

- استعمل **رقماً ثانوياً** مخصّصاً للمتجر — لا رقمك الشخصي.
- **سخّن الرقم الجديد**: استعمال بشري طبيعي أياماً قبل أوّل إرسال جماعي.
- ابدأ بأعداد صغيرة وارفعها تدريجياً.

الخطر قائم مهما احتطنا. البديل الرسمي (WhatsApp Cloud API) أأمن قانونياً لكنه
لا يقرأ المجموعات، ويلزمه اعتماد قوالب من Meta ورسوم لكل محادثة.

## الملفات

| الملف | الوظيفة |
|-------|---------|
| `src/index.js` | الحلقة الرئيسية: النبضة · توزيع الأوامر · عامل الإرسال والتهدئة |
| `src/session.js` | جلسة واتساب واحدة: QR · الاتصال · إعادة المحاولة · الإرسال |
| `src/authState.js` | حالة اعتماد Baileys مخزَّنة في قاعدة الموقع بدل القرص |
| `src/crypto.js` | تشفير المفاتيح (AES-256-GCM + HKDF) قبل مغادرتها الجهاز |
| `src/api.js` | عميل الواجهة الداخلية للموقع |
| `src/env.js` | قارئ `.env` صغير |
| `src/keygen.js` | توليد مفتاح التشفير |
