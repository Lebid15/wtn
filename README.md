# wtn — نظام لوحة وكلاء لشحن الألعاب (عربي / سوريا)

نظام لوحة وكلاء لشحن الألعاب، مستوحى من نظام تركي بإذن رسمي، معرَّب بالكامل
وبألوان مخصّصة ووسائل دفع سورية.

## الحالة الحالية
🔵 **مرحلة التأسيس (Foundation)** — التوثيق التقني جاهز، لم يبدأ الكود بعد.

```
reference/            ← التوثيق المرجعي (من النظام الأصلي)
  FEATURE_MAP.md        الخريطة الكاملة لكل الأقسام والميزات
  oyunpin/              لقطات قسم الألعاب (7 تبويبات)
  ayarlar/              لقطات قسم الإعدادات (14 تبويب)
  raporlar/             لقطات قسم التقارير
  screenshots/          لقطات عامة للوحة الرئيسية

docs/                 ← تصميم نظامنا الجديد
  ARCHITECTURE.md       المعمارية + الحزمة التقنية + تعدد المستأجرين
  DATABASE_SCHEMA.md    مخطط قاعدة البيانات الكامل
  ROADMAP.md            خطة البناء المرحلية (10 مراحل)
```

## قرار تصميم: واجهة غير متجاوبة (Non-Responsive)
التصميم بعرض كمبيوتر ثابت (1600px). في الجوال يظهر نفس تخطيط الكمبيوتر كاملاً
بحجم مصغّر، والمستخدم يكبّر بأصابعه (pinch-zoom) — مطابق تماماً للنظام المرجعي.

## نطاق النظام
- **مشمول:** قسم الألعاب (OyunPin) + الإعدادات (Ayarlar) + التقارير (Raporlar).
- **مُستبعد:** قسمَا الفواتير (Fatura) والكونتور (Kontor) — غير مطلوبين في السوق السوري.

## قرارات تصميم رئيسية
- **المحفظة:** رصيد واحد موقّع (signed balance) يقبل الموجب والسالب — القيمة
  السالبة تعني الدين (بدل نموذج المرجع: رصيد + دين منفصلين). مع حد ائتماني
  (Kredi Limiti) يمنع تجاوز حد سالب معيّن.
- **تعدد اللوحات:** سوبر أدمن + وكيل رئيسي + وكيل + متجر العميل، بنطاق فرعي لكل وكيل.
- **تعدد اللغات + ثيمات:** عربي أساسي (RTL) + ألوان وشعار مخصّص لكل وكيل.

## ملاحظة
لقطات الشاشة المرجعية قد تحتوي بيانات عملاء من النظام الأصلي. يُنصح إبقاء
هذا المستودع **خاصاً (private)**.
